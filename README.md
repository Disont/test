# My Games Hub

Личный компактный трекер игровой библиотеки.

- 74 игры из первой версии
- текущая игра и следующий шаг
- поиск и фильтры
- прогресс, уровни, заметки и задачи
- импорт и экспорт JSON
- AI-подсказка без спойлеров через OpenAI Responses API
- данные игр сохраняются локально в браузере

Рабочая версия публикуется через ChatGPT Sites. Секретный `OPENAI_API_KEY` хранится только в настройках среды Sites и никогда не добавляется в GitHub.
